# nadare

日本の山岳地帯における**雪崩リスク情報の公開・検索サイト**です。
バックカントリー初心者から経験者まで、雪崩リスクに関する情報をわかりやすく提供することを目的としています。

---

## 概要

**nadare** は、バックカントリー愛好者が安全に山行を判断できるよう、以下の情報を提供する Web プラットフォームです。

- 日本各地の山岳地帯における雪崩リスク情報
- 過去の雪崩発生事例
- 最新の気象データに基づくリスク評価

---

## 主な機能

### 地域別リスクマップ
北海道・東北・中部山岳・近畿など、日本全国の山岳エリアを選択し、エリアごとの雪崩ハザード情報を確認できます。

### 発生事例データベース
過去・最近の雪崩発生地点をインタラクティブなマップ上に表示します。同一地点での過去事例を検索することも可能です。

### 日別リスク予測
現在の気象状況をもとに、各エリアの雪崩危険度を毎日更新して提供します。

---

## 対象ユーザー

- バックカントリー入門者
- 雪崩に関する基礎知識を学びたい方
- 特定地域の雪崩発生履歴を調べたい方

---

## デザイン方針

- **シンプルさ優先** — 初心者が迷わず操作できるナビゲーション
- **地図ベースの情報提示** — 直感的に情報にアクセスできるUI
- **わかりやすいリスク表現** — 過度に専門的にならない、明瞭なリスクコミュニケーション
- **モバイル対応** — スマートフォンからも快適に利用できるレスポンシブデザイン
