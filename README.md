## クラブについて

### 前文

本会は「YOUTH-CLUB のメンバーに山の楽しみの一つとして山スキーを行う場を提供すること」を目的に、2010 年に当時の YOUTH-CLUB の有志メンバーが集まり JAC 同好会「バックカントリークラブ」として発足しました。以来、変遷はあるものの継続して YOUTH-CLUB 関連の団体として「事故遭難を無くし、楽しく長くバックカントリー活動を行うこと」をモットーに活動してきました。

### 運営方針

我々は、一定のリスクを前提とする「バックカントリー活動」の同好の士の集まりである。  
安全の礎は、会員各位が節度をもって行動するとともに、会員同士が互いに理解を深め、常に仲間としての配慮をもって行動することから生まれてくる信頼である。  
本会は、これら良好な人間関係を互いに築く意思のあるメンバーの集団でありたい。

また、運営に当たっては、同好の士が協力して運営する同好会組織であることを、会員各自が強く認識し、次項運営体制のメンバーであるなしにかかわらず、会員ひとり一人が、自らの参加する会の運営を支えるとの自覚のもと、経験・技術等に関係なく、それぞれの立場から自主的に運営にかかわることを共通の理解とする。

また、本会活動を通じ、会員がそれぞれの立場で常に自己研鑽に努めつつ、併せて会員相互の協力（持てる力を持ち寄りあい）により、スキー技術に留まらず、雪崩遭難対策等を身に着け適切に行動できる、それぞれのレベルで自立したバックカントリープレイヤーになることを目指していく。

> 出典：「バックカントリークラブの運営等について」（2023 年 12 月 19 日改定版）

## サイト構成

| ページ | 内容 |
|---|---|
| `index.html` | トップページ（クラブ紹介・お知らせ・活動内容・山行記録・入会案内・お問い合わせ） |
| `nadare.html` | 雪崩リスク情報ツール（地図・リスク表示・過去事例検索） |
| `css/style.css` | 共通スタイルシート |
| `js/app.js` | 雪崩ツール用 JavaScript |
| `data/cases.json` | 雪崩事故事例データ（書籍「雪崩事故事例集 190」ベース） |
| `docs/` | PDF 格納フォルダ（`bcc-rules.pdf` を配置するとダウンロード機能が有効） |
| `images/` | 画像フォルダ（`tsugaike.jpg` を配置するとヒーロー背景に表示） |

## 掲載方針

- **会員個人名は掲載しない**（代表者・事務局の氏名も非掲載、問い合わせ窓口はメールアドレスのみ）
- **写真は栂池スキー場の写真（2023.4）のみ使用**
- **入会条件**：要約版をページ本文に掲載し、正式全文は PDF ダウンロードとして提供
- 山行実績表はページ内に表形式で掲載（2025-26 シーズン：全 24 件）

## 技術要件

- **ホスティング**：GitHub Pages（`main` ブランチのルートから配信）
- **更新方法**：Claude Code でソースコードを編集し、`git push` でデプロイ
- レスポンシブ対応（PC / スマホ）
- 会員による記事投稿機能は当面不要
