# nadare
雪崩リスクの情報公開・検索サイトを作成、公開する
対象：バックカントリーを始めてみたい人
情報源：書籍の山岳雪崩大全、日本雪崩ネットワークのウェブサイト、国土交通省が公開しているパンフレットなど
対象地域は日本の山岳地帯全般
日本地図を5区分くらいの対象地域（北海道、東北、上越、中部山岳地帯、近畿など）に区分してユーザーが選択可能にする。
雪崩の発生事例は直近の事例を地図上で表示し、同じ場所での事例を過去にさかのぼって検索可能にする
直近の気象情報をもとに、本日のリスクまで表示する
サイトのデザインはシンプルに。
質問がある場合の連絡先は日本山岳会バックカントリークラブまで
