# バックカントリークラブ(BCC) ホームページ 要件定義書(v3)

## 1. 背景・目的
- BCCは2010年発足のJAC-YOUTHCLUB派生の同好会で、山スキー(バックカントリー)活動を行う会員44名の組織。
- 本サイトの目的は「入会希望者の勧誘」。活動内容・理念・入会条件を正しく伝え、問い合わせ・入会申込につなげる。
- 公開範囲:**完全公開**。JAC本体サイトとは**相互リンク**を張る形の**独立サイト**として構築する。

## 2. 参考サイト
- [アルパインスキークラブ(JAC Alpine Ski Club)](https://jac-asc.sakura.ne.jp/asc/)
  - メニュー構成:ホーム/クラブ紹介/入会案内/山行記録/投稿ガイド/旧HP
  - 山行報告と入会案内を軸にしたシンプルな構成 → BCCサイトも踏襲

## 3. ターゲットユーザー
- 主要ターゲット:JACおよびYOUTH-CLUB関連団体(沢登同好会Ⅱ、平日クラブ等)の会員
- 副次的ターゲット:JACサイト経由で流入する一般のJAC会員

## 4. サイトマップ(案)
1. トップページ:活動理念・栂池の写真・お知らせ
2. クラブ紹介(BCCとは):発足経緯・モットー・運営方針・会員構成
3. 活動内容:会の山行の仕組み、例会情報(月1回・第3火曜夜・Zoom/ハイブリッド)、雪崩講習会・入門研修
4. 山行記録・活動実績:2025-26シーズン実績一覧(表)
5. 入会案内
   - 入会条件(**要約をページに掲載+詳細はPDFダウンロード**)
   - 入会の流れ
6. お問い合わせ:メール(bcc@jac1.or.jp)への案内リンク

## 5. コンテンツ・掲載方針
- **会員個人名は掲載しない**(代表者・事務局の氏名も非掲載とし、問い合わせ窓口はメールアドレスのみ案内)
- **写真は添付の栂池スキー場の写真(2023.4)のみ使用**。他の写真素材は現時点でなし
- **入会条件**:要約版をページ本文に掲載し、正式な全文は「BCC運営等について(抜粋)」をPDF化してダウンロードできるようにする(既存Word資料からPDF変換)
- 山行実績表(21件の山行一覧)はページ内に表形式で掲載

## 6. 技術要件
- **更新方法**:Claude Codeでソースコード(HTML/CSS等)を編集し、デプロイする運用を想定
- **ホスティング**:上記「確認事項」で決定(A: WordPress+レンタルサーバー / B: 静的サイト+無料ホスティング)
- レスポンシブ対応(PC/スマホ)
- 会員による記事投稿機能は当面不要(勧誘目的の公開情報サイトのため)

## 7. 個人情報・プライバシー配慮
- 会員名は一切掲載しない方針のため、個人情報リスクは低い
- 写真(栂池)に写っている人物の顔が判別できる場合は、掲載可否を念のため確認
