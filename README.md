雪崩リスクの情報公開・検索サイトを作成・公開するプロジェクトです。

## 概要

nadare は、バックカントリーを始めてみたい人に向けて、雪崩リスクに関する情報を分かりやすく公開・検索できるWebサイトです。

日本の山岳地帯における雪崩リスク、過去の雪崩発生事例、直近の気象情報などをもとに、利用者が安全判断の参考にできる情報を提供します。

## 対象ユーザー

* バックカントリーを始めてみたい人
* 雪崩リスクについて基礎的に学びたい人
* 山岳エリアごとの雪崩事例やリスクを確認したい人

## 主な機能

### 1. 地域別の雪崩リスク情報

日本の山岳地帯全般を対象とし、日本地図を以下のような地域に区分して表示します。

* 北海道
* 東北
* 上越
* 中部山岳地帯
* 近畿 など

ユーザーは地図上または一覧から対象地域を選択できます。

### 2. 雪崩発生事例の表示

直近の雪崩発生事例を地図上に表示します。

また、同じ場所で発生した過去の雪崩事例をさかのぼって検索できるようにします。

### 3. 本日の雪崩リスク表示

直近の気象情報をもとに、対象地域ごとの本日の雪崩リスクを表示します。

## 情報源

本サイトでは、以下の情報を参考にします。

* 書籍『山岳雪崩大全』
* 日本雪崩ネットワークのWebサイト
* 国土交通省が公開しているパンフレット
* その他、雪崩・山岳安全に関する公的情報

## デザイン方針

サイトのデザインは、シンプルで分かりやすいものにします。

重視するポイントは以下です。

* 初心者でも迷わず使えること
* 地図上で直感的に情報を確認できること
* 雪崩リスクを過度に複雑化せず、分かりやすく伝えること
* スマートフォンでも見やすいこと
